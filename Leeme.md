# Sistema de Asistencia Dinámica y Auditoría Criptográfica v2.5
### Cátedra de Clínica Psicológica y Psicoterapias - Universidad Nacional de Córdoba (UNC)

Este repositorio contiene el código fuente completo y unificado para implementar el sistema.

## 📂 Contenido del Paquete
* `asistencia.py`: Motor de Python local para compilar códigos QR en PowerPoint (.pptx).
* `configuracion.txt`: Variables de vinculación directa externas.
* `GENERAR_ASISTENCIA.bat`: Ejecutable por lotes para Windows con un solo clic.
* `codigo_appscript.js`: Código del backend de Google Sheets con motor de informes y auditoría por gracia.
